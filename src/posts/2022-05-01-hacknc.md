## Overview

From May to November 2022 I facilitated game development workshops at HackNC in Chapel Hill, NC. I created a procedural level generation system for a 2D space game using the Godot engine as the workshop demo, then taught fundamental game development and programming concepts to students through Godot's visual scripting system.

The goal was to make programming approachable — visual scripting lets beginners connect logic without getting blocked by syntax, while still exposing the underlying concepts of variables, conditionals, and events.
