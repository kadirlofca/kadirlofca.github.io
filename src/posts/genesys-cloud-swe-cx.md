## Overview

From August to November 2023 I interned at Genesys Cloud in Durham, NC on their customer service platform — a screen-sharing application serving over 2,000,000 customers. I worked across the full stack: frontend features in Next.js and Redux, backend API optimization, and infrastructure as code.

## Frontend

I engineered scalable full-stack features using **Next.js**, **TypeScript**, and **Redux**. One of the core challenges on a high-traffic platform is keeping the UI consistent and fast under concurrent state changes — Redux gave us a predictable state model that made that manageable.

I also resolved complex frontend UI bottlenecks that were slowing the team's velocity and managed Git workflows (PRs, merge conflicts) for an international team.

## Backend & Infrastructure

I optimized backend API endpoints to handle 10% additional request volume while maintaining 99.99% availability and sub-200ms response times for new product features.

On the infrastructure side, I reduced provisioning time by 50% by writing reusable **Terraform modules** — abstracting repetitive resource definitions into composable IaC patterns the team could apply across environments.

## Testing & Compliance

I authored 30+ unit and integration tests, leveraging **Docker** and **Redis** to orchestrate isolated CI/CD environments. This contributed to a 20% decrease in regression bugs across the features I owned.

All work was conducted in a secure VPN environment with strict HIPAA Security and Privacy compliance — a meaningful introduction to regulated software development.
