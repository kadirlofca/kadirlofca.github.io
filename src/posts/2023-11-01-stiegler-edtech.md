## Overview

At Stiegler EdTech I worked as a Programming, SQL, Python, and C++ mentor in Charlotte, NC from November 2023 to June 2025. The role mixed hands-on technical instruction with systems thinking — improving how students learn, how TAs teach, and how automated tools grade.

## Teaching & Curriculum

I led a technical education initiative for a cohort of 200+ students. By designing targeted C++ remediation plans tailored to specific failure patterns, the cohort achieved a **100% pass rate**.

I also mentored 15+ junior teaching assistants on pedagogical best practices and debugging techniques — focusing on how to ask guiding questions instead of giving answers, and how to diagnose student confusion efficiently.

To reduce student debugging time by ~40%, I systematized the most common low-level failure patterns related to hardware interrupts and memory management into a shared knowledge base that TAs could reference during sessions.

## Robotics

I directed student projects involving Arduino-based robotics, overseeing real-time sensor integration and PID control loop architecture. Students went from software-only backgrounds to wiring and programming physical systems.

## AI Grading System

Stiegler used an automated AI-driven grading system. I identified that LLM hallucinations were producing inconsistent scores and architected rigorous evaluation benchmarks to measure and constrain the model's behavior — reducing hallucination rate by 30% in assessments.

## Data-Driven Improvements

I analyzed large-scale student performance datasets using SQL and Python to surface learning bottlenecks — which topics caused the most failures, which remediation approaches worked. Those findings drove curriculum updates that improved outcomes across subsequent cohorts.
