## Overview

[Santai.GG](https://santai.gg) is an open-source game statistics platform for the tactical shooter Spectre Divide — leaderboards, player stats, and tournament results. I joined as an active maintainer and contributor, eventually leading a full codebase overhaul and driving the product roadmap.

## Codebase Overhaul

The codebase had accumulated inconsistent typing and loose architectural patterns. I led a comprehensive overhaul to enforce strict TypeScript typing and consistent architectural conventions across the frontend and backend. This significantly improved developer velocity — fewer runtime surprises, faster onboarding, easier code review.

## Product & Growth

I defined the product roadmap and executed rapid feature iterations, which drove organic growth to **300+ weekly active users within 3 months** of joining. The features I prioritized were the ones players actually asked for: better leaderboard filtering, deeper per-player stat breakdowns, and faster page loads.

## Performance

With a live leaderboard serving the top 1000 players, database load was the primary scaling concern. I implemented **Redis caching** for high-read data to minimize database hits and deployed via **Railway** for simple, reliable hosting.

## Stack

TypeScript · Next.js · React · Supabase (PostgreSQL) · Redis · Railway
