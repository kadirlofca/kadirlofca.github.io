Government benefits programs are managed through large enterprise web portals. Millions of citizens depend on these systems, but the portals are desktop-first and offer nothing a smartphone user would expect: no push notifications, no biometric login, no offline support.

I built the native mobile and backend layer that bridged that gap. The mobile app wrapped the existing web portal in a native shell so citizens could get a real mobile experience without the portal needing to be rebuilt. On the backend, I built the cloud infrastructure for push notification delivery and an over-the-air config system that let us ship behavior changes without an app store release.
