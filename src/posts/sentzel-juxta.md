Game review aggregators reduce a game's entire identity to a single score. That number loses the nuance that actually drives decisions: whether the combat is tight, whether the story holds up, whether the performance is stable. Players and developers both need more than a Metascore.

<a href="https://juxta.gg" target="_blank" rel="noopener noreferrer">Juxta.gg</a> ingests review content, uses a large language model to extract structured attributes, and ranks games against each other per aspect using an AI-judge ELO system. Every game that enters the pipeline flows through automatically: content discovery, aspect extraction, deduplication, pairwise ranking comparisons, and storage. The result is a structured, ranked view of games grounded in what people who play the games actually discuss.

Players can browse and search games by aspect, discover hidden gems, and see how games rank against each other across specific dimensions. The platform is AWS-funded and in production.
