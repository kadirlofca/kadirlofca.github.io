## Overview

juxta.gg is a production AI-powered game intelligence and discovery platform I architected and shipped end-to-end as the sole engineer at Sentzel Labs. The goal: let players find games through natural language — queries like *"games that feel lonely and vast"* — powered by real semantic understanding, not keyword matching.

## AI Ingestion Pipeline

The backbone is a 10-activity durable pipeline on **Temporal.io**:

1. YouTube transcript ingestion
2. Aspect extraction via AWS Bedrock
3. pgvector deduplication
4. ELO ranking via LLM pairwise comparison
5. Description generation
6. DB commit

Temporal's durable execution model means automatic partial-failure recovery — no work is lost on retry. New games enter the system and flow through the full pipeline without manual intervention.

## Hybrid Semantic Search

Search delivers results in under 500ms by combining two signals:

- **ILIKE text scoring** for exact and fuzzy keyword matches
- **pgvector HNSW cosine similarity** over 1024-dimensional Amazon Titan V2 embeddings

The HNSW index makes approximate nearest-neighbor search fast enough for interactive queries at scale.

## AI-Adjudicated ELO Ranking

Game ranking uses an ELO system where matchups are judged by **Amazon Nova Lite** (via AWS Bedrock) rather than human votes. Authority-weighted K-factor scaling (1.2×) handles new entrants without full re-ranking, and every comparison is logged to an `aspect_comparisons` audit table.

## Infrastructure & Quality

- All cloud resources (EC2, ECR, S3, IAM) provisioned via **Pulumi IaC** — zero manual resource creation
- SSH-less deployment via AWS SSM
- CI/CD: GitHub Actions → Docker → ECR with keyless AWS auth via GitHub OIDC
- 26 codebase quality rules enforced via a custom test suite + ESLint; pre-push hook gates on 90% coverage
- 32 REST API endpoints covering game stats, aspect intelligence, ELO trajectories, head-to-head comparisons, PCA-reduced embedding visualization, and platform analytics
- 55 test files: Postgres integration tests via Testcontainers, Temporal workflow unit tests with time-skipping, Playwright end-to-end tests
